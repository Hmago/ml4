Improve a chapter of ML Study Notes with AI

Follow the steps in order. Steps 1–2 are once per computer. Steps 3–8 are once per chapter.

Harshit, do this once before sharing: push all your latest work to GitHub, and add your colleague as a collaborator at github.com/Hmago/ml4 → Settings → Collaborators.

1 Install the tools (once)

Open PowerShell: press Start, type PowerShell, press Enter. Paste this and press Enter. Accept any prompts.

winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Python.Python.3.12 -e
winget install --id EclipseAdoptium.Temurin.21.JDK -e

Close PowerShell and open it again, then run this (put in your own name and email):

py -m pip install numpy
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Install Agency: open aka.ms/agency and run the Windows install command shown on that page. Then close and reopen PowerShell.

2 Download the project (once)

cd $HOME
git clone https://github.com/Hmago/ml4.git

If a browser window asks you to sign in to GitHub, sign in.

3 Open Agency

cd $HOME\ml4
git pull
agency copilot
  • First time only: sign in with GitHub when asked.
  • If it asks "Do you trust the files in this folder?", choose Yes.

4 Select the model

Type /model, press Enter, choose Claude Opus 5.5 with the arrow keys, then press Enter.

This is the model used for the finished chapters. Claude Sonnet 5.5 uses fewer credits, and the images may need more fixing.

5 Allow all permissions

Type /allow-all, press Enter, and confirm with Yes. Without this, the AI stops to ask before every file it edits and every command it runs.

6 Pick a chapter and paste the prompt

1) Choose the chapter. They are listed in the recommended order.

2) Click Copy prompt, paste it into Agency (right-click or Ctrl+V), and press Enter.

7 Check the result


When it finishes, it gives you a link such as http://localhost:8000/#content/…. Open it in your browser and scroll through the chapter. If you don't get a link, type start the web app and give me the link to this chapter.



8 Save and publish


When you are happy with the chapter, type:


Commit only this chapter's changes and new images with a short message, then pull and push to main. If the pull conflicts in js/data/search_index.js, js/state.js or sw.js, don't merge them by hand: keep the incoming version, re-run the generators, bump the cache number again, then commit and push.


The website updates by itself a few minutes after the push.


Then click Mark as done ✓ above. For the next chapter, type /clear and repeat steps 6–8. If you closed the window, start again from step 3.
